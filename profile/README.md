## About

NTIC Solution is a Montréal-based technology and cybersecurity firm. We design, secure and operate environments where **everything is code**: infrastructure and workloads are declared, versioned and rebuilt from source rather than patched by hand.

## What we do

| :-- | :-- | :-- | :-- |
| Security hardening<br>Zero Trust access<br>Least-privilege identity | Network architecture<br>Virtualization<br>Hybrid cloud | Infrastructure as Code<br>GitOps delivery<br>Container platforms | Workflow orchestration<br>DevSecOps pipelines<br>Operational runbooks |

## How we build

| Principle | In practice |
| :-- | :-- |
| **Everything as code** | If it isn't declared in a repository, it doesn't exist. |
| **GitOps by default** | Changes land by reviewed commit — never by hand in a console. |
| **Reproducible by design** | Any environment can be rebuilt from source and the secret store. |
| **Centralized secrets** | One system of record, read at runtime. An exposed secret is rotated immediately. |
| **Least privilege** | Machines get narrowly scoped identities; elevated rights are temporary and revoked after use. |
| **Read-only first** | Every change starts with an inventory before anything is mutated. |
| **One change, one commit** | Every change is its own commit and its own rollback point. |
